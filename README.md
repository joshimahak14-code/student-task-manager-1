# 🎓 TaskFlow — Student Productivity Dashboard

> A modern, responsive, and visually stunning Student Task Manager web application built using **100% Pure HTML5 and CSS3** — no JavaScript, no frameworks, no libraries.

## ✨ Features

- 🌓 **Pure CSS Dark / Light Mode** — Seamless theme toggle using CSS checkbox hack with animated transitions.
- 📊 **Interactive Overview & Quick Filters** — Real-time task filtering via CSS `:has()` pseudo-class without a single line of JavaScript.
- 🎯 **Tactile Micro-Interactions** — Smooth hover elevations, spring bouncy icons, and realistic `:active` hold press-down feedback.
- 📋 **Rich Task Management** — Task cards with priorities (High, Medium, Low), deadlines, subjects, and completion states.
- 🍅 **Study Timer Widget** — Pomodoro-style visual timer ring.
- 📚 **Subject Breakdown** — Track progress across Data Structures, Web Development, DBMS, and OS.
- 📱 **Fully Responsive** — Optimized for desktops, tablets, and mobile devices with a sticky mobile bottom navigation bar.

## 🚀 Getting Started

No build tools or installation needed! Simply clone and open:

```bash
git clone https://github.com/joshimahak14-code/student-task-manager-1.git
cd student-task-manager-1
```

Double-click `index.html` to open it in any modern browser (Chrome, Edge, Firefox, Safari).
